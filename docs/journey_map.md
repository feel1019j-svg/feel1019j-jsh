# 저니맵 — 한 사람 · 한 시나리오 (M5-04)

- 시나리오: 박정민 사장님이 이번 달 마감 정산에서 순이익이 줄어든 걸 확인하고, 원인이 내 가게만의 문제인지 궁금해하다가, 부산 vs 전국 비교 화면을 보고 판단 근거를 얻어 다음 행동을 정하기까지 (가설 — 실제 인터뷰로 검증 전)
- 처음 들어오는 순간: 카드매출 앱과 현금 시재를 더해 이번 달 순이익을 계산하다가, 평소보다 눈에 띄게 줄어든 걸 발견하는 순간
- 마지막에 얻는 것: "내 가게만의 문제가 아니라 부산 지역 전체가 전국보다 더 어려운 상황"이라는 근거를 확인하고, 무리하게 비용을 줄이기보다 몇 달 더 지켜보기로 판단할 근거

|단계|행동|생각|감정 1~5|다음 단계로 가는 이유|기회|
|---|---|---|---|---|---|
|1. 마감 정산|카드매출 앱 알림과 현금 시재를 더해 이번 달 순이익 계산|"어? 저번 달보다 많이 줄었네"|3|줄어든 이유가 궁금해짐|매출 변화를 한눈에 보여주는 화면(가설)|
|2. 원인 찾기|동네 상인들과 얘기해보거나 포털에서 검색|"다들 그런 건지 우리만 그런 건지 도무지 모르겠다"|**2 (최저)**|답을 못 찾아 답답해서 다른 방법(지인 추천·검색)을 더 찾아봄|**여기가 핵심 기회 — 부산 vs 전국 비교를 바로 보여주는 화면**|
|3. 서비스 확인|링크를 열어 이번 달·작년 매출을 입력하고 결과 확인|"부산 전체가 전국보다 더 나쁘구나, 나만의 문제가 아니었네"|4|안심하고 판단 근거가 생김|결과 옆에 "이럴 때 보통 이렇게 한다"는 짧은 다음 행동 힌트(가설)|
|4. 결정·공유|무리한 인력 감축 대신 몇 달 더 지켜보기로 하고, 동네 상인에게도 링크 공유|"성급하게 결정 안 해도 되겠다"|4|(마지막 단계)|공유 버튼, 다음 달 재방문 유도(가설)|

- **감정 최저점**: 단계 2(원인 찾기) → 기능 후보: 부산 vs 전국 체감지수를 바로 나란히 보여주는 F-01 화면
- **떠나는 순간**: 단계 2에서 검색해도 답을 못 찾고 "그냥 내가 원래 이런 시기인가 보다" 하며 포기하는 순간(가설) → 붙잡을 장치: 회원가입 없이 링크 클릭 한 번으로 바로 결과가 보이게 하기, 검색 상위 노출이나 지인·상인회 공유로 접근 장벽을 낮춤
